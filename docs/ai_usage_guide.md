# AI 활용 기록 작성하기

> 문서 유형: **How-to** — 지원자가 `AI_USAGE.md`를 작성하는 방법입니다.

## 작성 원칙

1. 사용한 도구를 나열하기보다 어떤 문제를 맡겼는지 적습니다.
2. 프롬프트 전체 대신 제공한 맥락과 기대 결과를 요약합니다.
3. 제안을 채택, 수정, 거절한 이유를 적습니다.
4. 사람이 확인한 방법과 아직 남은 위험을 적습니다.
5. 비밀정보와 불필요한 전체 대화 로그는 제거합니다.

## 권장 양식

아래 내용을 프로젝트 루트의 `AI_USAGE.md`에 복사해 작성할 수 있습니다.

```markdown
# AI 활용 기록

## 사용 여부

- 사용함 / 사용하지 않음
- 도구 및 모델:

## 활용한 작업

| 작업 | AI에 제공한 맥락과 요청 | 결과를 사용한 방식 |
| :--- | :---------------------- | :----------------- |
| 예: API 타입 작성 | OpenAPI 문서와 기존 타입 규칙을 제공하고 타입 초안을 요청 | 초안을 수정해 사용 |

## 주요 판단

### 채택한 제안

- 제안:
- 채택 이유:
- 직접 수정한 내용:

### 거절하거나 다시 요청한 제안

- 제안:
- 문제점:
- 최종 결정:

## 검증

- 실행한 자동 검사:
- 직접 확인한 사용자 시나리오:
- 명세와 대조한 내용:

## 남은 한계

- 구현하지 못했거나 추가 확인이 필요한 내용:
```

AI를 사용하지 않았다면 사용 여부, 이유, 직접 사용한 문제 해결 및 검증 방법만 간단히 작성하면 됩니다.
